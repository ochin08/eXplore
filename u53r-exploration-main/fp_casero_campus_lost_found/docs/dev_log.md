M1: Project Planning and Design

Date: October 28, 2026
Milestone: M1, Project Design
Project Title: Campus Lost and Found System

Work Completed

I selected the Campus Lost and Found System as my Fundamentals of Programming project. I identified the problem of organizing records of lost and found belongings within the campus. I also identified the target users, inputs, outputs, and the main purpose of the application.

I designed eight record fields: item ID, item name, category, location, report date, status, estimated value, and contact email. I also established initial validation rules for item IDs, email addresses, dates, numeric values, and item statuses.

Decisions and Reasons

I chose a menu-driven Python console application because it is appropriate for my current programming level and allows me to practice fundamental programming concepts. I chose CSV for record storage because it is suitable for structured text data and can be handled using Python's built-in "csv" module.

I made the estimated value and contact email optional because these details may not always be available or necessary. I selected SDG 11, Sustainable Cities and Communities, as the project's related Sustainable Development Goal because the application aims to support a more organized campus community process.

Problems or Questions

One design consideration was deciding which fields should be required and which should be optional. I addressed this by making the core item details required while allowing the estimated value and contact email to be omitted when unknown or unnecessary.

Lessons Learned

I learned that project planning involves identifying the problem, users, data fields, and validation rules before writing the program. A clear design can help make implementation, testing, and code explanation easier.

Next Steps

My next milestone is to prepare the pseudocode and flowchart for the main menu and selected features. After that, I will begin building and testing a small CSV prototype.
